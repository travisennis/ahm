# ahm v1.1.0

A maintenance release, published as the migration waypoint into v2.0.0.

**This release is not a reduction.** It carries the same feature set as
v1.0.0's development line, and the only reason it exists is that v2.0.0
refuses to read a repository that is still on the legacy `.agents/ahm.json`
layout, and no previously published release can move a repository off it.

## If your repository is on the legacy layout

v2.0.0 refuses to run against `.agents/ahm.json`, deliberately, so a legacy
repository is never half-adopted. Move it with this release first:

```bash
ahm upgrade
ahm records migrate
```

`ahm upgrade` refreshes the ahm-managed files. `ahm records migrate` moves
`.agents/.tasks/`, `.agents/.research/`, and `.agents/exec-plans/` to
`.ahm/tasks/`, `.ahm/research/`, and `.ahm/exec-plans/`, writes
`.ahm/config.json`, installs the managed `.ahm/.gitignore`, and removes
`.agents/ahm.json`. It prints the `git add` and `git rm --cached` commands to
run afterwards. Review and commit those before moving on.

Then install v2.0.0 and run:

```bash
ahm init
```

If `ahm records migrate` reports that it cannot run, commit or discard the
uncommitted record changes it names and run it again.

## If your repository already uses `.ahm/`

Nothing to do. v1.1.0 reads and writes the committed `.ahm/` layout exactly as
v2.0.0 does, apart from the surfaces v2 removes. Upgrade to v2.0.0 directly.

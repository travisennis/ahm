# Design Plans

Design plans (ExecPlans) for large or cross-cutting work live here. This
directory is project-owned: `ahm` does not create, read, index, or validate
anything in it.

- `active/`: plans for work that is still in progress.
- `completed/`: plans whose work is finished and whose Outcomes &
  Retrospective section is filled in.

Follow [the ExecPlan workflow](../workflow/exec-plans.md) when writing one.
Plans written before this repository adopted `docs/exec-plans/` remain under
`.ahm/exec-plans/`; they are historical records and are not maintained. The
retired generated indexes inside `.ahm/exec-plans/` and `.ahm/research/` are
stale for the same reason: `ahm` no longer regenerates them, and `ADR 022`
keeps them in place rather than deleting them.

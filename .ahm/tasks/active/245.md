# Constrain task work promptFile to the repository root

## Problem

`taskWork.promptFile` in `.ahm/config.json` is repo-supplied, committed content,
and `buildTaskWorkPrompt` resolves it with no containment check: absolute paths
are used verbatim and relative paths go through `filepath.Join(root, ...)`
without rejecting `..`. The file's contents are appended to the prompt handed to
the external agent CLI, which uploads them to the model provider.

Reproduced with `promptFile: "../outside-secret.txt"`:

```
## Project Instructions

SUPER-SECRET-CONTENT
```

So cloning an untrusted repository and running `ahm task work` exfiltrates any
file the invoking user can read — `~/.aws/credentials`, `~/.ssh/id_rsa`, a
sibling repository's `.env` — to the configured provider. The read failure path
is silent by design (the feature is opt-in by presence), so nothing surfaces
that an out-of-tree file was read.

Task 162 introduced the feature and framed it as "a project prompt file";
nothing about that purpose requires escaping the repository.

## Relevant Files

- `internal/ahm/task_work.go:231-240` — `promptFile` resolution in
  `buildTaskWorkPrompt`.
- `internal/ahm/metadata.go` — `TaskWork.PromptFile` config field.
- `internal/ahm/path.go` — existing path containment helpers.
- `docs/guardrails/safety-and-permissions.md` — path and write boundary rules.
- `docs/references/workflow-spec.md` — `ahm.json` / `config.json` schema.

## Fix Direction

Reject absolute paths and any resolved path that escapes the repository root,
using the existing containment helper rather than a new ad-hoc check; resolve
symlinks before the containment test so a symlinked prompt file cannot be used
to step outside. Fail the command with an actionable error when the configured
path is out of tree — this is a misconfiguration, not an absent file, and must
not share the silent opt-in-by-presence path.

Document the constraint in the config schema reference. Check whether any other
config-supplied path (agent executables, session paths) has the same shape and
note findings rather than expanding scope silently.

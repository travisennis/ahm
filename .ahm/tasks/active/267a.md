# Derive project identity and resolve the home store root

## Summary

Task records need a project identity before they can live outside the project.
Implement the derivation from ADR 023 and make it observable.

Add `internal/ahm/identity.go`:

    func canonicalRemoteKey(rawRemote string) (key string, ok bool)
    func canonicalPathKey(projectRoot string) (key string, err error)
    func projectKeyFor(projectRoot string) (key string, kind string, rawRemote string, err error)
    func storeDirName(key string) string

`canonicalRemoteKey` returns the lowercased `host/owner/repo` form: scheme,
userinfo, default port, trailing `.git`, and trailing slash removed, scp-like
syntax accepted, non-default ports kept, and credentials never hashed or
persisted. It reports `ok == false` for `file://` URLs and local-path remotes
so the caller uses the path rule. `canonicalPathKey` hashes the
symlink-resolved absolute project root with SHA-256. `storeDirName` returns
`<slug>-<hash8>`.

The remote is read with `git remote get-url origin` through
`cleanGitEnvironment` in `internal/ahm/git.go`, cached once per command. Use
`origin`; otherwise a sole remote; several remotes without `origin` fall back
to the path rule rather than guessing.

Add `internal/ahm/store.go` with `storeRoot`, `resolveStore`, the registry
load and write helpers, and the store's `project.json` state file, per the
Interfaces section of the ExecPlan. `AHM_HOME` must be absolute; reject a
relative value.

Add the `store` command group in `internal/ahm/cli.go` with one subcommand,
`path`, printing the root, key, and records directory, and the same fields
under `--json`. Register it in the CLI reference docs that this milestone
touches.

## Acceptance

- `internal/ahm/identity_test.go` covers a golden table: scp-like and URL
  remotes for one repository produce one key; uppercase is lowercased;
  credentials are stripped; a default port is dropped and a non-default port
  is kept; `file://` and local-path remotes take the path rule; two clones and
  a symlinked path resolve to one key.
- `ahm store path` prints the same key and directory from two clones of one
  repository, and a `path`-kind key in a repository with no remote.
- `AHM_HOME` redirects the store root; a relative value exits 2.
- `just ci` passes.

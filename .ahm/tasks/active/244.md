# Escape backslashes before pipes in generated index table cells

## Problem

`escapeCell` escapes `` ` `` and `|` but never escapes `\` itself, and it does
so after those replacements would need it. A title containing `\|` becomes
`\\|` in the cell: the `\\` renders as a literal backslash and the `|` is left
unescaped, splitting the table row.

Reproduced — `ahm task create 'Pipe \| break'` yields

```
| [001](active/001.md) | Pipe \\| break | Open | ...
```

in `.ahm/tasks/index.md`. The damage is cosmetic, but indexes are generated
output that `ahm status` and `ahm index --dry-run` then diff for staleness, so a
malformed cell is churn in a compatibility surface.

Task 024 added backtick, angle-bracket, and square-bracket escaping but did not
handle the escape character itself.

## Relevant Files

- `internal/ahm/indexes.go:405` — `escapeCell`.
- `internal/ahm/indexes_test.go` — `TestEscapeCell` and the golden index tests.

## Fix Direction

Escape `\` first, before `` ` ``, `|`, and the bracket replacements, so the
inserted escape characters are not themselves re-escaped and pre-existing
backslashes survive. Extend `TestEscapeCell` and the golden index fixture with a
title containing `\`, `\|`, and `` \` ``.

## Acceptance Notes

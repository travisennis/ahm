# Signal tracking tasks whose child tasks are all complete

## Summary

Surface tracking tasks whose child tasks are all Completed or Cancelled so an
agent gets a signal to close the tracker itself instead of leaving it in
Tracking with nothing left to track.

- `ahm doctor` / `ahm status` emit a new warning-tier finding
  `task_tracking_children_complete` for an active Tracking task with at least
  one child, every child Completed or Cancelled, and the tracker's own
  dependencies satisfied. The warning also fires through post-mutation
  validation, so completing the last child warns immediately.
- `ahm task ready`, `ahm task next`, the `ahm prime` Ready section, and the
  generated task index Next Ready Queue include such tracking tasks.
- The task workflow template directs agents to complete a tracker surfaced
  this way instead of skipping it as not directly workable.

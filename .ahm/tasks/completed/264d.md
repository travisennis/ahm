# Collapse install and upgrade into one idempotent ahm init

## Summary

Remove `ahm upgrade` and make `ahm init` create-or-reconcile: on an
up-to-date repository it changes nothing; on a repository with obsolete
ahm-owned configuration it removes only the obsolete fields and preserves
unrelated unknown metadata; it always leaves a project-owned `AGENTS.md`
untouched. Remove the records, task, and ADR migrations and the legacy
`.agents/ahm.json` layout support, including the dual-layout indirection in
`workflow_paths.go`; root detection accepts only `.git` or
`.ahm/config.json`. This repository is the only consumer, and it holds no
legacy layout, so no compatibility shim is required.

## Acceptance Notes

- [x] `ahm init` on an up-to-date repository exits 0 and writes nothing.
      Verified in a scratch repository and by `TestInitIsIdempotent`,
      `TestInitIsIdempotentOutsideManagedRepository`, and
      `TestInitDryRunReportsNothingWhenUpToDate`: the second run prints nothing
      and every file keeps its bytes and modification time.
- [x] `ahm init` on a repository whose config carries `taskWork` removes that
      field only, preserving unrelated unknown metadata. Verified by
      `TestInitDropsObsoleteKeysAndPreservesUnknownMetadata`; `adr_legacy_format`
      was the only finding that named a removed command and is reworded.
- [x] A project-owned `AGENTS.md` survives `ahm init` and `ahm init --force`
      unchanged, and no path creates or overwrites it. Verified by
      `TestInitLeavesProjectOwnedAgentsMdAlone` and the idempotence snapshot.
- [x] `ahm upgrade`, `ahm records migrate`, `ahm task migrate`, and
      `ahm adr migrate` no longer exist as commands. Verified against the built
      binary: unknown command for `upgrade` and `records`, unknown subcommand
      for `task migrate` and `adr migrate`.
- [x] A repository with a legacy `.agents/ahm.json` fails with a message that
      names the final v1 release it must upgrade with first, rather than
      silently treating the directory as unmanaged. Verified by
      `TestInitRefusesLegacyLayout`, `TestInitRefusesLegacyLayoutForExplicitRoot`,
      `TestDetectManagedRootFailsOnLegacyLayout`, and
      `TestDetectManagedRootFailsOnLegacyLayoutInParent`.
- [x] `just ci` passes.

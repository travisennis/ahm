# Delete task work, audit, and groom with their shared delegation plumbing

## Summary

Remove the delegation surface. `ahm task work`, `ahm audit`, and
`ahm task groom` share `task_agents.go`, `task_session.go`, and
`task_parsers.go`, so they are removed as one unit, together with their tests,
`internal/ahm/testdata/agents`, the `smoke-agents` and
`capture-agent-fixtures` recipes, `scripts/capture-agent-fixtures.sh`, and
`docs/guardrails/external-agent-orchestration.md`. Follow-through: drop the
`taskWork` config seed and its validation, and any task-work finding codes.

## Acceptance Notes

- [x] `ahm task work`, `ahm audit`, and `ahm task groom` fail as unknown
      commands, and `ahm task --help` no longer lists them. Verified with a
      binary built from this commit: `unknown subcommand "work" for "ahm task"`,
      `unknown command "audit" for "ahm"`, `unknown subcommand "groom" for
      "ahm task"`, and `ahm task --help` lists 16 subcommands without `groom`
      or `work`.
- [x] No code, recipe, script, or guardrail references agent definitions,
      argument builders, session capture or resume, JSONL parsing, golden
      transcripts, or provider smoke tests. `scripts/task-workflow.sh`
      (session capture and resume through `cake`) was deleted with the rest;
      see the ExecPlan decision log.
- [x] No test makes a network call and `AHM_AGENT_SMOKE` no longer selects
      any test path. `rg -n "AHM_AGENT_SMOKE" .` returns nothing, and no test
      imports `net/http` or dials a socket.
- [x] `ahm doctor` and `ahm status` report no task-work or grooming findings.
- [x] `just ci` passes.

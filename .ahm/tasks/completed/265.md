# End generated ADR files with a single newline

## Summary

`renderADR` in `internal/ahm/adrs.go` appended a blank line after the body, so
every ADR created by `ahm adr create` (with `--body-file`, a description, or
stdin) ended in two newlines. `docs/adr/**` is linted by `just docs-md-lint`,
so a freshly created ADR failed CI with markdownlint MD012 ("Multiple
consecutive blank lines"). Found while creating ADR 022.

## Acceptance Notes

- [x] `renderADR` emits exactly one trailing newline for an ADR with a body,
      and `internal/ahm/test_helpers_test.go` has an assertion helper for it.
- [x] `TestADRCreateBodyFile` and the new `TestADRCreateEndsWithSingleNewline`
      cover a body file whose content ends with blank lines.
- [x] Verified on a throwaway repository with a freshly built binary:
      `ahm adr create ... --body-file body.md` now writes a file whose last
      bytes are `.\n`.
- [x] `just ci` passes, including `just docs-md-lint`.

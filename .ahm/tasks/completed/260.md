# Upgrade setup-just action off deprecated Node 20

## Problem

Every CI run shows a deprecation annotation:

> Node.js 20 is deprecated. The following actions target Node.js 20 but are
> being forced to run on Node.js 24: extractions/setup-crate@4993624604c307fbca528d28a3c8b60fa5ecc859

GitHub will eventually stop running Node 20 actions, so this needs an upgrade
before it breaks CI.

Root cause chain (verified 2026-07-31):

- `.github/workflows/ci.yml` uses `extractions/setup-just@v3` (resolves to
  v3.1.0).
- `extractions/setup-just@v3.1.0` is a composite action that internally pins
  `extractions/setup-crate@4993624604c307fbca528d28a3c8b60fa5ecc859` (# v1.4.0).
- `extractions/setup-crate@v1.4.0` declares `runs.using: 'node20'` in its
  `action.yaml`, which is what the annotation flags.

## Relevant Files

- `.github/workflows/ci.yml` — `extractions/setup-just@v3`
- `.github/workflows/release.yml` and `.github/workflows/semantic-pr.yml` —
  audit for the same runtime issue. `release.yml` now uses
  `goreleaser/goreleaser-action@v7`; `semantic-pr.yml` uses
  `amannn/action-semantic-pull-request@v6`, which is already Node 24.

## Fix Direction

- Bump `extractions/setup-just@v3` to `@v4` in `.github/workflows/ci.yml`.
  Verified: `extractions/setup-just@v4` (v4.0.0) internally pins
  `extractions/setup-crate@0551596312d4008a6dfbc4d3c38fa20eaef46d2d`
  (# v2.0.0), which declares `runs.using: 'node24'`. Inputs
  (`just-version`, `github-token`) are unchanged, so the call site stays the
  same.
- Alternatively, pin `extractions/setup-crate@v2` directly and drop
  setup-just — only if the bump alone does not clear the annotation.
- Keep the repo convention of `@vN` tags used by the other actions.
- The workflow audit also found `goreleaser/goreleaser-action@v6` used Node 20;
  it was upgraded to `@v7` alongside the setup-just change.

# Record ahm's structured-work product boundary

## Summary

Create and accept an ADR that narrows ahm to research, ExecPlans, ADRs, and tasks, supersedes ADR 016, and defines compatibility treatment for removed documentation surfaces.

## Decision To Record

Ahm manages four structured record families: research, ADRs, ExecPlans, and
tasks. General project documentation is project-owned output that managed work
may reference or update, not a fifth ahm work type.

The replacement ADR must:

- supersede ADR 016 in full;
- remove `ahm docs check`, the `project-docs` validation scope,
  `projectDocs` configuration, and `ahm context docs`;
- retain deterministic relative-link validation for the four structured
  record families as part of default doctor/status validation;
- classify the removals as an intentional breaking CLI/config change and
  define the upgrade and release-note treatment;
- keep safe, metadata-proven cleanup of obsolete `.agents/DOCS.md` files
  without continuing to expose or install a documentation procedure;
- revise the vision from documentation-health enforcement to workflow-record
  integrity enforcement.

Historical research and ADR text remains intact except for normal
supersession links and status changes.
